HTML Structure:
We create a simple form (). Inside the form, we have three radio buttons. Each radio button has: type="radio": Identifies them as part of a radio button group. name="selection": Ensures that only one radio button in this group can be selected at a time. value="pageX.html": This is the crucial part! The value of each radio button is set to the URL of the corresponding confirmation page (e.g., page1.html, page2.html, page3.html). id and label: For accessibility, linking the label to the input.
